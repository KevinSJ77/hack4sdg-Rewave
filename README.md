💧 REWAVE

Every Drop Deserves Another Life.

SDG 6 – Clean Water and Sanitation

REWAVE is an interactive digital prototype exploring decentralised greywater recycling for sustainable campus water management.

🌍 Problem Statement

College hostels generate significant amounts of wastewater from showers and washbasins, while freshwater continues to be used for gardening, flushing, and other utilities.

This creates an opportunity to treat and safely reuse greywater, reducing unnecessary freshwater consumption.

💡 Our Solution

REWAVE proposes a modular greywater recycling system that collects, filters, monitors, and redirects appropriately treated wastewater for non-drinking purposes.

Our website demonstrates this concept through interactive simulations and planning tools.

⚡ Key Features

- Interactive Campus Network: Visualises the proposed water recycling system.
- Smart Water Quality Signal: Simulates water-quality decisions using a traffic-light model.
- Water Filtration Simulation: Interactive demonstration of the filtration process.
- Irrigation & Flushing Simulations: Explores potential applications of treated greywater.
- Budget Calculator: Evaluates planning costs against a ₹30 lakh budget.
- Water Impact Explorer: Estimates potential water recovery and reuse.

The current prototype uses simulated data, not physical sensor readings.

🛠️ Tech Stack

- HTML5 – Website structure
- Internal CSS3 – Styling and responsive design
- Internal JavaScript – Simulations and interactive functionality
- GitHub – Version control
- GitHub Pages – Deployment

CSS and JavaScript are embedded directly within the HTML files.

⚙️ How to Run

1. Clone or download this repository.
2. Open "index.html" in a browser to launch REWAVE.
3. Open "Water Filtration Model (1).html" to access the standalone simulation.

No additional installation or backend setup is required.
